Quick Install

                    
Install the VPSMon agent on any Linux or Windows server. Create an enrollment token first, then run the command on the target machine.

                    

                        

                            
Linux (Ubuntu/Debian/Rocky/Alma)

                            
curl -sSL https://monitoring.solverix.io/static/agent/install-agent.sh | sudo bash -s -- \
  --token YOUR_TOKEN \
  --server https://monitoring.solverix.io \
  --name my-server-01

                        

                        

                            
Windows (PowerShell as Admin)

                            
Invoke-WebRequest -Uri "https://monitoring.solverix.io/static/agent/vpsmon-agent.py" -OutFile "C:\vpsmon-agent.py"
python C:\vpsmon-agent.py --enroll --server https://monitoring.solverix.io --enroll-token YOUR_TOKEN --name WIN-SRV-01
